# 🚀 AI-Powered Data Ingestion & Quality Audit Pipeline

👉 **[View the Generated AI Audit Report (AI_INSIGHTS.md)](https://github.com/dhirajtripathi93/docker-workshop/blob/main/pipeline/AI_INSIGHTS.md)**

## 📌 Executive Summary
A production-grade, containerized data ingestion pipeline designed to stream multi-million-row NYC TLC Taxi datasets into a PostgreSQL warehouse. This project integrates a pre-load AI validation framework utilizing **OpenAI** and **Anthropic** APIs to perform automated anomaly detection, generate executive audit reports, and output exploratory data visualizations.

## 🛠️ Technology Stack
* **Core Engineering:** Python 3.13, Pandas, SQLAlchemy, Psycopg
* **Infrastructure & Containerization:** Docker, Docker Compose, PostgreSQL 18, pgAdmin 4
* **AI & Data Quality:** OpenAI API (gpt-4o-mini), Anthropic API (claude-3-5-haiku-latest)
* **Data Visualization:** Matplotlib, Seaborn
* **Dependency Management:** Astral UV

## ⚙️ Architecture & Features
* **High-Performance Ingestion:** Loads massive CSV payloads into PostgreSQL using memory-safe, chunked execution via SQLAlchemy.
* **LLM-Driven Anomaly Detection:** Extracts a 10,000-row sample to automatically audit bad records, identify statistical outliers, and flag logical data anomalies (e.g., impossible distance-to-fare ratios).
* **Automated Audit Reporting:** Programmatically generates a structured Markdown report (`AI_INSIGHTS.md`) and distribution scatter plots prior to full database commits.
* **Containerized Orchestration:** Services (`pgdatabase`, `pgadmin`, `taxi_ingest`) are seamlessly orchestrated using Docker Compose with persistent volume mapping and host networking.
* **Lightning-Fast Builds:** Replaced standard `venv` and `pip` with **Astral UV**, reducing Python dependency resolution and container build times to seconds.

## 🚀 Quick Start Guide

### 1. Prerequisites
* **Docker & Docker Compose** installed.
* Active API keys for **OpenAI** and **Anthropic**.

### 2. Environment Setup
Create a `.env` file in the root directory of the project to securely store your API keys. 

*Note: Ensure there are no quotation marks or trailing spaces in this file.*
```env
OPENAI_API_KEY=sk-proj-your_openai_key_here
ANTHROPIC_API_KEY=sk-ant-your_anthropic_key_here
```

### 3. Execution
Build the images and spin up the database and ingestion containers. Run this command from the directory containing the `docker-compose.yaml`:

```bash
# Tear down any existing cached networks/volumes to ensure a clean slate
docker compose down -v

# Build and launch the pipeline
docker compose up --build
```

### 4. View Results
Once the ingestion finishes, you can explore the results in three ways:

1. **The AI Audit Report:** Open `AI_INSIGHTS.md` in your text editor (or click the link at the top of this file) to read the automated data quality assessments generated by ChatGPT and Claude.
2. **The Visualizations:** Open `images/anomaly_scatter.png` to view the scatter plot of flagged anomalies vs. normal taxi trips.
3. **The Data Warehouse:** 
   * Navigate to `http://localhost:8085` in your web browser.
   * **Login:** `admin@admin.com` / **Password:** `root`
   * Register a new server connecting to host `localhost` (or `pgdatabase` depending on your Docker network mode), user `root`, password `root`.
   * Query the `yellow_taxi_trips` table inside the `ny_taxi` database.

## ⚠️ Troubleshooting Tips for GitHub Codespaces
If you are running this pipeline inside a cloud IDE like GitHub Codespaces and encounter a `Temporary failure in name resolution` error during the Python ingestion phase:
1. Codespaces occasionally corrupts internal Docker DNS routing. 
2. Ensure your `docker-compose.yaml` is utilizing `network_mode: "host"` for all services to bypass the virtual network bridge and connect directly to the internet.
3. Force a complete environment reset by running `docker compose down -v` followed by `sudo service docker restart` in your terminal.
